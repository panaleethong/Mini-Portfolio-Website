MY INSPIRATION

ทำไมต้องวิศวกรรมอิเล็กทรอนิกส์และระบบคอมพิวเตอร์

"อาจารย์เคยสงสัยไหมคะว่า คนคนหนึ่งที่ไม่เคยคิดมาก่อนเลยว่าตัวเองจะสนใจวิชาคอมพิวเตอร์ หรือแม้แต่จะเลือกเรียนต่อในสาขาที่เกี่ยวข้องกับคอมพิวเตอร์ จะค้นพบตัวเองและตัดสินใจเดินมาบนเส้นทางนี้ได้อย่างไร" สวัสดีค่ะ ดิฉันนางสาว ปณาลี ทองมีปั่น กำลังศึกษาอยู่ในระดับชั้นมัธยมศึกษาปีที่ 6/2 โครงการห้องเรียนพิเศษ วิทยาศาสตร์ คณิตศาสตร์ Science Mathematics Program สำหรับดิฉัน จุดเริ่มต้นไม่ได้มาจากการเป็นคนที่เก่งคอมพิวเตอร์หรือมีความฝันที่จะเป็นวิศวกรมาตั้งแต่เด็ก แต่เกิดจากการได้ลองทำสิ่งใหม่ๆ ทั้งการเขียนโปรแกรม การสร้างเว็บไซต์ และการพัฒนาโครงงานต่างๆ จนค้นพบว่าตนเองมีความสุขกับการสร้างสิ่งต่างๆ ด้วยความคิดของตัวเอง โดยเฉพาะเมื่อได้เห็นผลงานที่ลงมือทำสามารถทำงานได้จริง จากความสนใจเล็กๆ จึงกลายเป็นความอยากรู้อยากเห็นว่าเบื้องหลังเทคโนโลยีเหล่านั้นทำงานอย่างไร และทำให้ดิฉันต้องการเป็นคนที่สามารถสร้างและพัฒนาสิ่งเหล่านั้นขึ้นมาได้ด้วยตนเอง เมื่อดิฉันด้ค้นพบความสนใจของตนเอง ดิฉันจึงเริ่มเรียนรู้เพิ่มเติมผ่านค่ายและกิจกรรมด้านคอมพิวเตอร์และวิศวกรรม โดยได้ทดลองเขียนโปรแกรมภาษา Python และ Java สร้างเว็บไซต์ด้วย HTML และ CSS รวมถึงเรียนรู้การทำงานของอุปกรณ์อิเล็กทรอนิกส์และไมโครคอนโทรลเลอร์ เช่น การควบคุมหุ่นยนต์ การใช้งานเซนเซอร์ และการสร้างผลงานด้วย Arduino ประสบการณ์เหล่านี้ทำให้ดิฉันเข้าใจว่าการพัฒนาเทคโนโลยีต้องอาศัยทั้งความรู้ด้านฮาร์ดแวร์และซอฟต์แวร์ที่ทำงานร่วมกัน ตลอดการเรียนรู้ ดิฉันพบกับปัญหาหลายครั้ง ทั้งการเขียนโปรแกรมที่ไม่เป็นไปตามต้องการและการทดลองที่ไม่สำเร็จ แต่สิ่งเหล่านี้สอนให้ดิฉันรู้จักค้นหาสาเหตุ ศึกษาข้อมูลเพิ่มเติม และทดลองแก้ไขด้วยตนเอง จนได้ฝึกการคิดอย่างเป็นระบบ ความอดทน และความพยายามที่จะเรียนรู้สิ่งใหม่ๆ อยู่เสมอ

ทำไมต้องมหาวิทยาลัยศิลปากร?

เหตุผลที่ดิฉันเลือกมหาวิทยาลัยศิลปากร คณะวิศวกรรมศาสตร์และเทคโนโลยีอุตสาหกรรม สาขาวิชาวิศวกรรมอิเล็กทรอนิกส์และระบบคอมพิวเตอร์ เพราะเป็นสาขาที่ครอบคลุมความสนใจของดิฉัน ทั้งการเขียนโปรแกรม ระบบควบคุม ระบบ Embedded และปัญญาประดิษฐ์ AI โดยเฉพาะการนำฮาร์ดแวร์และซอฟต์แวร์มาประยุกต์ใช้ร่วมกันเพื่อสร้างเทคโนโลยีที่ใช้งานได้จริง อีกทั้งการได้พูดคุยกับรุ่นพี่ของมหาวิทยาลัยยังทำให้ดิฉันเห็นภาพการเรียนรู้และการลงมือปฏิบัติของสาขานี้ชัดเจนยิ่งขึ้น จึงมั่นใจว่าที่นี่เป็นสถานที่ที่เหมาะสมสำหรับการพัฒนาความรู้และความสามารถของดิฉัน หากได้รับโอกาสเข้าศึกษา ดิฉันตั้งใจที่จะพัฒนาทักษะทั้งด้านการเขียนโปรแกรม ระบบอิเล็กทรอนิกส์ และ AI ผ่านการเรียนและกิจกรรมต่างๆ อย่างเต็มความสามารถและเต็มที่อย่างถึงที่สุด ในอนาคต ดิฉันมีเป้าหมายที่จะเป็น AI / Machine Learning Engineer หรือ Software Developer ที่สามารถนำความรู้ทางวิศวกรรมมาสร้างสรรค์เทคโนโลยีเพื่อแก้ไขปัญหาและสร้างประโยชน์ให้กับผู้คน สำหรับดิฉัน การเดินทางมาถึงจุดนี้อาจไม่ได้เริ่มต้นจากความชอบที่มีมาตั้งแต่แรก แต่เกิดจากการกล้าลองเปิดโอกาสให้ตัวเองได้เรียนรู้ จนค้นพบสิ่งที่ต้องการทำจริงๆ ดิฉันเชื่อว่าความตั้งใจ ความพยายาม และความกระตือรือร้นในการเรียนรู้จะช่วยให้ก้าวผ่านความท้าทายต่างๆได้ และหวังว่าจะได้รับโอกาสเป็นส่วนหนึ่งของมหาวิทยาลัยศิลปากร เพื่อพัฒนาตนเองและเติบโตเป็นวิศวกรที่สามารถสร้างเทคโนโลยีที่มีคุณค่าในอนาคต
